# Бабказавозная

Статический сайт (HTML + CSS), репозиторий github.com/SofiaKrupina/babkazavoz, публикация через GitHub Pages из ветки main, корень.

## Где что
- `index.html` — обложка, `main.html` — главная, `style.css` — стили обеих.
- `images/` — картинки под именами из HTML.
- `input/` — исходные 22 картинки с именами по времени (2026-10-30 02.45.16.jpg и т.д.), не править.
- `scripts/make_images.py` — раскладывает `input/` в `images/` и убирает белый фон у title, sign, wallet, yellow-sign. Запуск: python с Pillow, `python -I scripts/make_images.py`.

## Что легко сломать
- Вёрстка на `position: absolute` с размерами в `%` и `vw`; рассчитана на широкий экран (ноутбук), на телефоне не адаптирована.
- Соответствие картинок именам угадано по виду. Неоднозначно: `label-about` и `label-when` (две светло-коричневые плашки), четыре бумажки `paper-*`. Менять в таблице MAP в `make_images.py`.

## Решения
- Комментарии в коде нейтральные, без подсказок разработчику.
- Публикация: https://sofiakrupina.github.io/babkazavoz/ . Файлы заливались через веб-интерфейс GitHub (у git на этом Mac нет доступа к аккаунту, gh не установлен); локальная копия сброшена на origin/main.
- Мусор в подвале main.html («[Ссылка] Страница не найдена…») удалён по решению владельца 2026-10-30.
