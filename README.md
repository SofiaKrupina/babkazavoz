# БАБКАЗАВОЗНАЯ

Сайт-концепт вымышленной районной телепередачи «Бабказавозная» — главного независимого источника новостей, вещающего с дворовой скамейки: сплетни, расписание эфиров, ведущие и соцсети. Учебный проект: вёрстка выполнена на HTML и CSS без JavaScript.

**Сайт:** https://sofiakrupina.github.io/babkazavoz/

## Разделы сайта

- **Обложка** (`index.html`) — бумажка с названием на ковре и табличка «Кликните, чтобы узнать больше», которая ведёт на главную страницу.
- **О проекте** — о чём передача и чем она занимается.
- **Где, как и когда?** — эфиры по вторникам, средам и пятницам в 20:00 на канале 67.
- **Телефон** — номер, на который можно позвонить со сплетней.
- **Ведущие** — «газетный разворот» с тремя ведущими.
- **Мы в соцсетях** — Telegram, TikTok / Shorts, ВКонтакте и RuTube (ссылки пока ведут на `#`).
- **Подвал** — шуточные выходные данные «СМИ».

Меню наверху главной страницы закреплено и переводит к нужному разделу.

## Технологии

HTML, CSS (`position: absolute`, `position: sticky`, `flex`, размеры в `vw` и `%`), шрифты Marck Script и Exo 2 с Google Fonts. Сайт опубликован на GitHub Pages.

## Структура проекта

- `index.html` — обложка;
- `main.html` — главная страница;
- `style.css` — стили обеих страниц;
- `images/` — картинки: фоны, бумажки, плашки заголовков, иконки соцсетей и декор;
- `input/` — исходные картинки (22 файла), из которых собрана папка `images/`.

Для раскладки картинок по именам и удаления белого фона у четырёх из них (`title`, `sign`, `wallet`, `yellow-sign`) использовалась автоматическая обработка вспомогательным скриптом, который написал ИИ-ассистент. Скрипт не является частью сайта и в репозиторий не добавлен; сам сайт написан только на HTML и CSS.

### Важные уточнения

- Основной код HTML и CSS написан ИИ по моему заданию и эскизу. Моя часть в коде — подбор значений (положение, размеры, наклоны) и исправление ошибок.
- В коде репозитория комментарии нейтральные, пометок «ИИ» нет: за разделение ролей отвечает таблица выше.
- Сайт рассчитан на широкий экран (ноутбук): размеры в `vw` и `%` масштабируют его по ширине окна, но на телефоне он не адаптирован.
- Соответствие картинок именам файлов в `images/` определялось по виду, поэтому сходные картинки (две плашки заголовков и четыре бумажки) могли быть перепутаны.
