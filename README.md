# Бабказавозная

Учебный проект: сайт-пародия на районную телепередачу «Бабказавозная» (канал 67) — сплетни, расписание эфиров, ведущие, соцсети. Вёрстка выполнена на HTML и CSS, без сборки и скриптов.

- Сайт: https://sofiakrupina.github.io/babkazavoz/

## Страницы

- `index.html` — обложка: бумажка с названием на ковре и табличка-ссылка на главную страницу.
- `main.html` — главная страница по блокам:
  1. О проекте и где смотреть (эфиры вт, ср, пт в 20:00 на канале 67);
  2. Телефон для сплетен;
  3. Ведущие;
  4. Соцсети (Telegram, TikTok / Shorts, ВКонтакте, RuTube);
  5. Подвал с «юридическим» текстом.
- `style.css` — стили обеих страниц.
- `images/` — картинки: фоны (`carpet.jpg`, `wood.jpg`), бумажки (`paper-*`), плашки заголовков (`label-*`), иконки соцсетей (`icon-*`) и декор.
- `input/` — исходные картинки, из которых собран `images/`.
- `scripts/make_images.py` — раскладывает `input/` в `images/` и убирает белый фон у части картинок.

Открыть сайт локально: открыть `index.html` в браузере. Шрифты Marck Script и Exo 2 подключаются с Google Fonts, нужен интернет.

## Как устроена вёрстка

Размеры и отступы заданы в процентах и `vw`, поэтому страница масштабируется вместе с шириной окна. Элементы расставлены через `position: absolute`. Бумажка или плашка — это блок с картинкой на всю ширину и текстом поверх неё (`.paper`, `.label`). Меню закреплено сверху (`position: sticky`).

## Использование ИИ

ИИ-ассистент (Claude) использовался в небольшом объёме:

- помог сделать сайт адаптивным: размеры в `vw` и `%`, чтобы страница подстраивалась под ширину экрана;
- помог сделать кнопки кликабельными: пункты меню с переходом к нужному блоку, плавная прокрутка, табличка на обложке со ссылкой на главную страницу;
- на последнем этапе помог навести порядок: убрал из кода рабочие комментарии, разложил картинки по папкам и опубликовал сайт на GitHub Pages.
