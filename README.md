# Бабказавозная

Сайт-пародия на районную телепередачу «Бабказавозная» (канал 67): сплетни, расписание эфиров, ведущие, соцсети. Статический сайт на HTML и CSS, без сборки и скриптов.

## Страницы

- `index.html` — обложка: бумажка с названием на ковре и табличка-ссылка на главную страницу.
- `main.html` — главная страница по блокам:
  1. О проекте и где смотреть (эфиры вт, ср, пт в 20:00 на канале 67);
  2. Телефон для сплетен;
  3. Ведущие;
  4. Соцсети (Telegram, TikTok / Shorts, ВКонтакте, RuTube);
  5. Подвал с «юридическим» текстом.
- `style.css` — стили обеих страниц.
- `images/` — картинки (собираются из исходников в `input/` скриптом `scripts/make_images.py`): фоны (`carpet.jpg`, `wood.jpg`), бумажки (`paper-*`), плашки заголовков (`label-*`), иконки соцсетей (`icon-*`) и декор.

## Как запустить

Открыть `index.html` в браузере. Шрифты Marck Script и Exo 2 подключаются с Google Fonts, поэтому нужен интернет.

## Как устроена вёрстка

Все размеры и отступы заданы в процентах и `vw`, поэтому страница масштабируется вместе с шириной окна. Элементы расставлены через `position: absolute`.

- Бумажка или плашка — блок с картинкой на всю ширину и текстом поверх неё (`.paper`, `.label`).
- Позиция и ширина каждого элемента — в `style.css`: `left`, `top`, `width`. Высота блока страницы — `height` у `.block`.
- Размер текста на бумажке — `font-size` в `vw`.
- Меню закреплено сверху (`position: sticky`). Плашки учитывают его высоту через `scroll-margin-top`.

## Что доделать

- Ссылки в блоке соцсетей ведут на `#`, нужны настоящие адреса.
- У декоративных картинок пустой `alt`.
